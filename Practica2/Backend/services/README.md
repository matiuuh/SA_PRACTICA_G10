# Servicios Backend

Esta carpeta agrupa los servicios del backend con enfoque SOA.

## Servicios planeados

- `auth-service`
- `localidades-service`
- `funciones-service`
- `reservas-service`
- `pagos-service`

## Convencion sugerida

Cada servicio puede tener su propia estructura NestJS, su propia base de datos y su propio `Dockerfile`.
