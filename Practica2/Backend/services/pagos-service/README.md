# pagos-service

Base inicial para el servicio de pagos.

## Responsabilidades

- registro de pagos
- control de estados de pago
- registro de transacciones
- consumo o publicacion de eventos relacionados con la compra

## Estructura sugerida

- `src/pagos/controllers`
- `src/pagos/services`
- `src/pagos/dto`
- `src/pagos/entities`
- `src/pagos/events`
